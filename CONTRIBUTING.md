# Contributing

Follow [build.md](docs/build.md) for setup and tests. Use isolated fictional workspaces and run the full JavaScript/Python suite and appropriate native tests before proposing a change.

Preserve original bytes, literal values, uncertainty and provenance. Interpretations must remain explicit and reviewed. Changes and migrations must be recoverable; do not silently assign scientific meaning to undocumented codes or missing values.

Keep changes focused and describe the concrete problem, behavior, validation and known limits. Add meaningful regression tests for defects. Avoid committing runtime distributions, private research, credentials, machine-specific paths or internal diagnostics.

Report ordinary bugs through repository Issues with version, OS, reproduction, expected and actual behavior. Use fictional or minimized data. Never upload confidential datasets. Follow SECURITY.md for vulnerabilities. Contributions are provided under the project's AGPL-3.0-only license unless a file explicitly retains a third-party license.
